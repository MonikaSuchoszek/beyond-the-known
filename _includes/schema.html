{%- comment -%} schema.org JSON-LD, emitted from head.html on every page as a single @graph. Nodes that are always present: * WebSite (#website) - the site itself, per-locale `inLanguage` * Person (#person) - site.name, used as both author and publisher Nodes added per page type, detected the same way the layouts do: * posts (page.collection == 'posts') -> BlogPosting + BreadcrumbList * category pages (page.category set) -> CollectionPage + BreadcrumbList * tag pages (page.tag set) -> CollectionPage + BreadcrumbList * year archives (page.year set) -> CollectionPage + BreadcrumbList * locale indexes -> nothing beyond WebSite/Person Breadcrumbs start at the locale index (from site.languages), never at the site root, so a Polish post breadcrumbs to /pl/ and not to /. Every string goes through `jsonify`, which supplies its own quotes and escapes quotes/newlines coming out of front matter - do not wrap those outputs in "". URLs are absolute and canonical: page URLs are run through canonical_url.html first, the same include head.html uses for rel="canonical", so the @id values here match the canonical URLs exactly. {%- endcomment -%} {%- assign base = site.url | append: site.baseurl -%} {%- assign schema_locale = page.locale | default: site.languages[0].locale -%} {%- assign schema_lang = schema_locale | split: '_' | first -%} {%- comment -%} This page's own canonical, absolute. {%- endcomment -%} {%- include canonical_url.html url=page.url -%} {%- assign schema_url = canonical_path | prepend: base -%} {%- comment -%} The index of this page's locale, used as breadcrumb root. {%- endcomment -%} {%- assign home_path = site.languages[0].index -%} {%- assign home_name = site.title -%} {%- for language in site.languages -%} {%- if language.locale == schema_locale -%}{%- assign home_path = language.index -%}{%- endif -%} {%- endfor -%} {%- include canonical_url.html url=home_path -%} {%- assign home_url = canonical_path | prepend: base -%}
